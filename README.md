# AniTracker

Трекер новых серий аниме и глав манги с [AnimeLib](https://v5.animelib.org): парсит страницу уведомлений, запоминает уже известные релизы в БД и присылает в Telegram только новые.

## Как работает

1. Раз в `CHECK_INTERVAL_MINUTES` минут демон открывает страницу уведомлений через Playwright (сохранённая сессия браузера).
2. Каждое уведомление превращается в структурированную запись: тайтл (по ID с сайта), команда озвучки/перевода, номер серии или главы, качество.
3. Новые релизы сохраняются в БД (`episodes`); повторные не дублируются (уникальный индекс на тайтл + команду + номер + качество).
4. Все ещё не отправленные уведомления доставляются в Telegram; недоставленные остаются в очереди и повторяются на следующем цикле.

## Установка и запуск

```bash
poetry install
playwright install chromium   # если браузер ещё не установлен
```

Заполните `.env`:

```env
URL=https://v5.animelib.org/...        # страница уведомлений
USER_DATA_DIR=./temp                   # профиль браузера с сохранённой сессией
DATABASE_URL=sqlite:///anitracker.db   # по умолчанию SQLite; для PostgreSQL: postgresql+psycopg://...
TELEGRAM_BOT_TOKEN=...                 # токен от @BotFather
TELEGRAM_CHAT_ID=...                   # ваш chat_id (сначала нажмите /start у бота)
TELEGRAM_PROXY=                        # опционально: socks5h://127.0.0.1:10808
CHECK_INTERVAL_MINUTES=30
```

```bash
poetry run python main.py
```

Демон пишет лог в `anitracker.log`. Для автозапуска при старте Windows создайте задачу в планировщике, запускающую `poetry run python main.py` (задача нужна только для старта, дальше процесс живёт сам).

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа: демон, APScheduler, lock-файл, логирование |
| `tracker.py` | Оркестрация одного цикла: парс → сохранить → отправить |
| `parser.py` | Playwright + извлечение данных из текста уведомлений |
| `repository.py` | Работа с БД: дедупликация, очередь на отправку |
| `notifier/` | Отправка сообщений в Telegram (поштучно, с повторами) |
| `db/` | Модели SQLAlchemy и engine |
| `alembic/` | Миграции БД (`poetry run alembic upgrade head`) |

## Особенности

- Тайтл идентифицируется числовым ID из URL сайта (`/anime/25412--...`), а не названием — названия могут совпадать, URL меняются.
- Уведомления вида «Добавлено N новых глав» без номеров пока пропускаются.
- Если уведомления по какой-либо причине не происходят, то они не пропадают, а копятся и будут отправлены когда такая возможность будет.
